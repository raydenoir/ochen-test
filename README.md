# Смысл — мастерская иллюстраций

Веб-редактор автоматически собирает композиции из исходных SVG-объектов Figma. AI помогает подобрать объекты из каталога, а редактор размещает их на холсте.

## Запуск

Понадобится Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес `Local` из вывода Vite. При первом смысловом запросе сервер скачает MiniLM с Hugging Face (около 140 МБ). С полным кэшем модель запускается офлайн. Сборка по названиям доступна сразу.

## Короткая демонстрация

1. В режиме **По замыслу** введите «Большие идеи рождаются в команде» и нажмите **Собрать композицию**.
2. В режиме **Из объектов** введите `Кошелёк, монета, лампа (фон)`. Выберите формат «Портрет» и соберите сцену.
3. Передвиньте объект, смените палитру и нажмите **Скачать SVG**. В векторном редакторе раскройте группу композиции, чтобы выделить отдельный объект.

| Знания открывают двери | Большие идеи — вместе | Деньги на чёрный день |
| :---: | :---: | :---: |
| ![Знания открывают двери](examples/education-album.svg) | ![Большие идеи — вместе](examples/team-square.svg) | ![Деньги на чёрный день](examples/savings-square.svg) |
| Альбом · [SVG](examples/education-album.svg) · [Проект](examples/education-album.json) | Квадрат, L и S · [SVG](examples/team-square.svg) · [Проект](examples/team-square.json) | Квадрат, фон за краем · [SVG](examples/savings-square.svg) · [Проект](examples/savings-square.json) |

Любой JSON из таблицы можно загрузить кнопкой **Открыть** и продолжить редактирование.

## Возможности

- **Холст и слои.** Пять форматов кадра. Объекты можно добавлять из библиотеки, перемещать, поворачивать, дублировать, удалять, менять их роль и порядок слоёв. Доступна отмена действий.
- **Детализация.** Для S и L загружаются отдельные исходные SVG. Можно задать детализацию всей сцены и выбрать другую для отдельного слоя. Общий масштаб композиции сохраняет исходные относительные размеры.
- **Фон и цвет.** Главные объекты цветные, фоновые — монохромные. У холста есть три исходных оформления и прозрачный вариант. Три встроенные палитры и импорт JSON автоматически перекрашивают сцену. Цвета фона доступны объектам, фон использует свою группу цветов. Образец JSON есть в справке.

## Как устроены SVG

- **Хранение.** В [библиотеке](design/library/) лежат 40 оригинальных SVG с тенями и манифест с габаритами. Для каждого из 10 видов объектов есть главный и фоновый варианты в S и L.
- **Извлечение.** Редактор выбирает файл по виду объекта, роли и детализации, загружает его по требованию и переиспользует для всех повторов. Сервер смыслового подбора возвращает совпадения из того же каталога.
- **Переиспользование и экспорт.** Компоновщик рассчитывает позиции, повороты и общий масштаб. Палитра меняет цвета исходных контуров и теней, геометрия сохраняется. Каждый объект экспортируется отдельной редактируемой векторной группой со своими ID масок и градиентов.

## AI-инструменты

- **OpenAI Codex** — разработка и проверки.
- **Многоязычная MiniLM через Transformers.js** — локальный подбор объектов по замыслу. Сложная метафора может потребовать уточнения.
- **Jev через TypeSafe** — дополнительный режим смыслового подбора, проверенный на подставных ответах. Для подключения задайте `INTERPRET_PROVIDER=jev` и `TYPESAFE_API_KEY` в окружении. В этом режиме текст замысла отправляется в TypeSafe.

## Запуск на сервере

Скопируйте [`.env.example`](.env.example) в `.env` и задайте `PORT` по требованиям хостинга. Сервер по умолчанию слушает `0.0.0.0`; если хостинг задаёт `HOST` через панель, укажите там `0.0.0.0`. Для MiniLM оставьте `INTERPRET_PROVIDER=local`. Если хостинг сбрасывает файлы при перезапуске, укажите постоянный записываемый каталог в `MODEL_CACHE_DIR`. По умолчанию модель хранится в `.cache/models/`.

```sh
npm ci --include=dev
npm run build
npm start
```

Node.js раздаёт редактор, SVG и API с одного адреса. HTTPS настраивается у хостинга или обратного прокси. Прокси должен сохранять исходный `Host`. Если нужны лимиты по IP посетителя, укажите точные адреса прокси в `TRUSTED_PROXY_IPS`, настройте перезапись `X-Forwarded-For` и ограничьте прямой доступ к Node.js этим прокси.

`npm test` запускает тесты. `npm run examples` воспроизводит примеры.
